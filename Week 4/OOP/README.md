## Description
Object-Oriented Programming python program calculates the area and perimeter of a rectangular land plot based on user input.

## Files
- **main.py**:User interface
- **rectangle.py**: rectangle class with attributes length and width
- **methods**: '__init__()', 'get_area()','get_perimeter()','display_info()'

## How to Run
1. Open VS Code
2. Run Python main.py file
3. Enter the length and width
